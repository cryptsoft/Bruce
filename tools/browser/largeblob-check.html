largeBlob wire-format check

Drives authenticatorLargeBlobs (CTAP 0x0C) through a real browser, which is the one client that was never written from this firmware.

Run this twice. Once against a token built before the parameter renumbering and once after. Before the fix the write step should fail; after it, it should round-trip. A pass on the old firmware would mean the whole finding is wrong, which is worth knowing more than a pass on the new one.

Serve over localhost -- WebAuthn needs a secure context, so file:// will not do: python3 -m http.server -d tools/browser 8000
